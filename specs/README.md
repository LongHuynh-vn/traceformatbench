# Specs

One file per feature, written by the student before any agent implements it.
Name files `NNN-short-name.md` (e.g., `001-f0-raw-serializer.md`).

## Template

```
# <Feature name>

## Goal
One or two sentences.

## Inputs
Types, shapes, where they come from.

## Outputs
Types, shapes, exact format.

## Edge cases
- ...

## Tests that must pass
- ...

## Out of scope
- ...
```
